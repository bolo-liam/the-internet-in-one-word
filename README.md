# The Internet in One Word

One word for the whole internet: **Toilet**.

The entire internet is read on the toilet, and it is mostly crap. It makes the reader laugh first, then nod.

## How it works

`main.py` writes the single word `Toilet` to `/output/entry.txt` (UTF-8, 6 characters, one word, inside the 1–30 character gate).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
